alpine-proot

Alpine Linux в Termux через proot (aarch64).

Установка

echo "deb [trusted=yes] https://thatcool-lab.github.io/alpine-proot/ ./" > $PREFIX/etc/apt/sources.list.d/alpine-proot.list
pkg update
pkg install alpine-proot
alpine

Файлы

  • Packages — индекс пакетов
  • Packages.gz — сжатый индекс
  • alpine-proot_1.0_aarch64.deb — сам пакет

Ручная установка

curl -LO https://thatcool-lab.github.io/alpine-proot/alpine-proot_1.0_aarch64.deb
dpkg -i alpine-proot_1.0_aarch64.deb
